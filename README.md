# Mon portfolio 🌟


## Technologies utilisées
- HTML
- Vanilla (Js)
- Tailwind CSS
- Lordicon
- BoxIcons

### Prérequis
- Node.js

### Lancement

1. **Cloner le dépôt**

   ```bash
   git clone https://github.com/kekelidiane/portfolio.git

2. **Lancer le serveur**
   Vous pouvez utiliser n'importe quel serveur HTTP statique. Par exemple avec `npx` :
   ```bash
   npx serve .
   ```
   Ou avec Python :
   ```bash
   python -m http.server 3000
   ```

3. **Accès au rendu**
   ```bash
   http://localhost:3000
   ```
